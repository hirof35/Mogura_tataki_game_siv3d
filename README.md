Siv3D もぐら叩き Pro
OpenSiv3D で実装された、軽快な動作とハイスコア記録機能を備えた「もぐら叩き」ゲームです。
絵文字（Emoji）をテクスチャとして活用し、視認性の高いUIとゲーム性を実現しています。

🎮 ゲーム概要
3x3の穴からランダムに出現するターゲットを、制限時間内にクリックしてスコアを競います。

🐹 モグラ: 叩くと +10点。

💣 爆弾: 叩くと -30点。出現率は約20%のトラップ要素。

制限時間: 30秒。

ランキング: 上位3位までのハイスコアを自動で score.json に保存・表示します。

✨ 実装のこだわり
動的なアニメーション:

サイン波（Sin関数）を用いた滑らかな「ひょっこり」動くアニメーションを実装。

音演出の工夫:

外部ファイルに依存せず、GMInstrument を利用してその場でSEを生成。開発の自己完結性を高めています。

データ永続化:

JSON形式によるスコア保存機能を搭載。起動時に過去の記録を読み込みます。

UI/UX:

残り時間、リアルタイムスコア表示、タイムアップ時のリザルト画面を完結にまとめています。

🛠 技術スタック
Language: C++20

Framework: OpenSiv3D (v0.6.x)

Data Handling: JSON (score.json)

📋 遊び方
OpenSiv3D のプロジェクトで Main.cpp にソースコードを貼り付けます。

ビルドして実行します。

マウス左クリック: ターゲットを叩く。

Enterキー: タイムアップ後のリトライ。

📐 設計思想
本プロジェクトは、「最小限のコードで最大限のゲーム体験」を提供することを目標に構築されました。アセット管理からスコア保存までのフローを数時間（あるいはそれ以下）で構築可能な「アジャイルな開発構造」のプロトタイプとしての側面も持っています。
